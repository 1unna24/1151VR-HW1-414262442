| Main Camera

- 開啟 Unity Hub
- 建立 Unity 3D 專案

- 熟悉 Unity 編輯器介面

- 使用 Scene 視窗進行 3D 場景操作

- 建立個人 GitHub Repository。
- Repository 設定為 Public
